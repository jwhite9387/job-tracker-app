# Job Tracker App

A full-stack web application for tracking job applications and managing the hiring pipeline.

## Tech Stack
- React
- Node.js
- Express
- SQLite

## Features
- Add, update, and delete job applications
- Track application status (applied, interviewing, offer, rejected)
- Filter applications by status
- Dashboard with application statistics

## Getting Started

### Backend
cd server  
npm install  
npm run dev  

### Frontend
cd client  
npm install  
npm start
